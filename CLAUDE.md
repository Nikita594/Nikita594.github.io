# Репозиторий nikita594.github.io

Сайт на GitHub Pages. В корне — старая учебная страница «Страны» (`index.html`, `css/`, `image/`), её не трогаем.

Основной проект — **«Ритм»**, планировщик задач и недели для одного пользователя (16 лет, Россия, MacBook + телефон).
Интерфейс только на русском, неделя с понедельника. Полностью бесплатно, без аккаунтов, без внешних сервисов и аналитики,
данные только на устройстве (IndexedDB).

- `ritm-app/` — исходники приложения.
- `ritm/` — готовая сборка, которую раздаёт GitHub Pages: https://nikita594.github.io/ritm/ (появляется после `npm run release`).
- `ritm-app/PLAN.md` — утверждённый план: схема данных, решения, порядок работ.
- Исходное задание — версии 1 и 2 (см. PLAN.md). Версию 2 начинать только после того, как пользователь проверит версию 1.

## Стек

React 19 + TypeScript 7 + Vite 8, Tailwind 4, Dexie 4 (IndexedDB), date-fns 4 (локаль ru), chrono-node (только `ru`, для дат в быстром вводе),
vite-plugin-pwa (service worker, манифест), vite-plugin-singlefile (однофайловая сборка), Vitest.
Recharts — добавить в версии 2 для графиков. Новых зависимостей без нужды не добавлять.

## Команды (из `ritm-app/`)

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки |
| `npm test` | тесты логики (Vitest) |
| `npm run typecheck` | проверка типов |
| `npm run build` | PWA-сборка в `dist/` |
| `npm run build:single` | однофайловая сборка в `dist-single/index.html` |
| `npm run release` | обе сборки + копирование в `../ritm/` (`ritm/ritm-offline.html` — один файл) |
| `npm run e2e` | проверки в Chromium: офлайн, file://, 375 px и т. д. Нужны собранные `dist/` и `dist-single/`. В облачной среде: `PLAYWRIGHT_PATH=/opt/node22/lib/node_modules/playwright npm run e2e` |

После каждого шага: `npm run typecheck && npm test`, сборка, `npm run e2e`, отдельный коммит.

## Устройство кода

- `src/db/` — Dexie: `types.ts` (все типы записей), `db.ts` (схема и версии), `seed.ts` (первый запуск: «Входящие», 8 категорий), `settings.ts` (настройки key-value + значения по умолчанию).
- `src/domain/` — чистая логика без React, с тестами рядом (`*.test.ts`). Всё, что можно протестировать, — сюда.
- `src/features/<раздел>/` — экраны.
- `src/ui/` — общие компоненты (`kit.tsx`), иконки (свои SVG), `Screen`, тосты.
- `src/lib/` — hash-роутер (`#/today`, `#/list/<id>`…), service worker, тема.
- `e2e/` — сценарии Playwright (`scenarios.mjs`) и мини-сервер, раздающий `dist/` по пути `/ritm/`.

## Принятые решения

- Даты хранятся строками `ГГГГ-ММ-ДД` по местному времени, время дня — минутами от полуночи, моменты — миллисекундами. Это убирает ошибки часовых поясов.
- id — случайные строки (`src/lib/id.ts`, через `crypto.getRandomValues`: `randomUUID` недоступен в некоторых контекстах file://).
- Встроенные категории имеют постоянные id (`study`, `english`, `sat`, `work`, `channel`, `sport`, `games`, `rest`).
- Список «Входящие» — обычный список с id `inbox`, удалить нельзя.
- Схема версионируется: старые `db.version(n)` не менять, добавлять новую версию с `upgrade`; для старых резервных копий — шаг миграции данных экспорта.
- Таблицы версии 2 (цели, копилка, разборы) созданы сразу в версии схемы 1.
- `base: './'` — сборка работает в любой подпапке и с file://.
- Однофайловая сборка: `__SINGLE_FILE__ = true`, service worker не регистрируется. В Chromium IndexedDB на file:// работает и переживает перезапуск; Safari с file:// не проверен — советуем Chrome/Яндекс Браузер.
- Service worker регистрируем сами (`src/lib/sw.ts`), `registerType: autoUpdate`; при обновлении показываем тост «Перезагрузить».
- Базовые стили — в `@layer base`, иначе они перебивают утилиты Tailwind 4.
- Тема: класс `.dark` на `<html>`, цвета — CSS-переменные (`bg-surface`, `text-muted`, `bg-accent`…), выбор дублируется в localStorage, чтобы не мигало при загрузке.
- Быстрый ввод (`src/domain/quickAdd.ts`): сначала свои токены (`!N`, `#категория`, `~список`, длительность), потом `rewrite()` приводит «к пятнице», «до среды», «вс», «20.10», «2 часа дня» к формам, которые понимает chrono, затем chrono (`chrono-node/ru`, `forwardDate`). Поправки: «в 7» без «утра/вечера» и без минут = 19:00; только время → сегодня, а если прошло — завтра; день недели, совпадающий с сегодняшним, → через неделю; одиночные «неделя», «месяц» и т. п. — не дата. В JS `\b` не работает с кириллицей — границы слов через `(?<![\p{L}\p{N}])`. Неизвестная `#категория` остаётся в названии и подсвечивается.
- Приоритеты: 0 нет, 1 низкий, 2 средний, 3 высокий. В быстром вводе `!1` — высокий, `!2` — средний, `!3` — низкий.
- Копилка (версия 2): суммы в копейках/центах, показывать и в ₽, и в $; курс задаётся в настройках (`usdRateKopecks`).
- `npm audit` ругается на `braces` внутри vite-plugin-singlefile — это инструмент сборки, в приложение не попадает.
- Lighthouse больше не проверяет PWA; устанавливаемость проверяем по манифесту, иконкам и service worker (e2e).

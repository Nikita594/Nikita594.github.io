# Ритм

Планировщик задач и недели. Работает без интернета, данные хранятся только на устройстве.

- Адрес: **https://nikita594.github.io/ritm/**
- Однофайловая версия: **https://nikita594.github.io/ritm/ritm-offline.html** — скачать и открывать двойным кликом. Ссылка на неё есть и в приложении: «Настройки» → «Резервная копия» → «скачать ritm.html».

## Сборка

Нужен [Node.js](https://nodejs.org) 22 или новее.

```bash
cd ritm-app
npm install
npm run dev            # посмотреть в браузере во время разработки
npm test               # тесты
npm run release        # собрать обе версии и положить в ../ritm/
```

`npm run release` делает две сборки:

| Версия | Где появляется | Как открыть |
|---|---|---|
| PWA (устанавливаемое приложение) | `ritm/` | выложить на сайт; после коммита в `main` GitHub Pages обновит https://nikita594.github.io/ritm/ |
| Один HTML-файл | `ritm/ritm-offline.html` | двойной клик, сайт не нужен |

По отдельности: `npm run build` (только PWA, в `dist/`) и `npm run build:single` (только файл, в `dist-single/index.html`).

## Установка

**Mac, Chrome или Яндекс Браузер.** Откройте https://nikita594.github.io/ritm/ → значок установки справа в адресной строке (или меню ⋮ → «Установить Ритм»). Приложение появится в Launchpad и откроется в отдельном окне.

**Mac, Safari (macOS Sonoma и новее).** Откройте адрес → меню «Файл» → «Добавить в Dock».

**iPhone.** Только Safari: откройте адрес → кнопка «Поделиться» → «На экран „Домой“».

**Android.** Chrome: откройте адрес → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

После первого открытия приложение работает без интернета.

**Однофайловая версия.** Скачайте `ritm-offline.html` и откройте двойным кликом. На Mac лучше открывать в Chrome или Яндекс Браузере: в них данные из такого файла точно сохраняются. Данные у файла и у установленного приложения разные: это два отдельных хранилища.

## Быстрый ввод

В строке «Добавить задачу» можно писать всё сразу, в любом порядке. Под строкой видно, что распознано, ещё до сохранения.

| Пример | Что получится |
|---|---|
| `английский завтра в 18:00 1ч !2 #учёба` | завтра в 18:00, 1 час, средний приоритет, категория «Учёба» |
| `эссе в пятницу в 7 вечера` | ближайшая пятница, 19:00 |
| `SAT через 3 дня 2ч !1` | через 3 дня, 2 часа, высокий приоритет |
| `урок 45 мин в 10 часов` | 45 минут, в 10:00 |
| `слова каждый день #англ` | повтор каждый день, категория «Английский» |
| `зал по пн, ср, пт в 19` | повтор по понедельникам, средам и пятницам в 19:00 |
| `оплатить телефон каждый месяц 15-го` | повтор 15-го числа каждого месяца |
| `алгебра 20.10 ~школа` | 20 октября, в список «Школа» |

`!1` — высокий приоритет, `!2` — средний, `!3` — низкий. `#` — категория (можно начало слова: `#англ`), `~` — список.

## Горячие клавиши (на компьютере)

`N` — новая задача, `/` или `⌘K` — поиск, `T` — Сегодня, `W` — Неделя, `P` — таймер, `?` — все клавиши. Работают и на русской раскладке.

## Обновления

Когда на сайте выходит новая версия, приложение скачивает её само и показывает «Приложение обновилось — Перезагрузить». Данные при обновлении не трогаются.

## Резервная копия

Данные живут только в браузере на этом устройстве. Если почистить данные браузера или удалить приложение, они пропадут. Safari на iPhone может удалить данные сайта, который долго не открывали. Поэтому раз в неделю приложение тихо напомнит сделать копию.

- **Сохранить:** «Настройки» → «Резервная копия» → «Сохранить копию». На компьютере скачается файл `ritm-backup-ГГГГ-ММ-ДД.json`. На iPhone откроется «Поделиться»: выберите «Сохранить в Файлы» или отправьте себе в Telegram. Храните копию где-нибудь ещё: в облаке, в «Избранном» Telegram, на флешке.
- **Восстановить:** «Настройки» → «Резервная копия» → «Восстановить из файла» → выбрать файл. Приложение покажет, что в файле, и после подтверждения **заменит** все текущие данные данными из копии.
- **Перенести на другое устройство:** сохранить копию на одном устройстве, передать файл (AirDrop, Telegram) и восстановить на другом. Синхронизации между устройствами нет: каждое хранит свои данные.

## Если что-то не так

- **«Браузер не даёт сохранять данные».** Так бывает в Safari с файлом `ritm.html`, открытым с диска, и в приватном режиме. Откройте файл в Chrome или Яндекс Браузере или пользуйтесь сайтом.
- **«Что-то сломалось».** Нажмите «Перезагрузить»: данные хранятся отдельно и никуда не денутся.
